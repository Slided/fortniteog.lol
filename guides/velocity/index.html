Quick Start Guide

Go to: Velocity Discord Server

  1. Copy any version hash (looks like "version-xxxxxxxxxxxxxxxx") from Velocityupdates (MUST BE WINDOWS).
  2. Paste that into the version hash and download.
    Recommended hash: 89b6c70d8f7f42ac
  3. Once downloaded (LIVE-WindowsPlayer-version-xxxx.zip):
    • Find your Roblox install folder: C:\Users\xxxx\AppData\Local\Roblox\Versions\version-(CurrentVersion)
    • Remove all content in it.
    • Put your spoofed version of the client in.
  4. You are now free to run and inject.

Tip: Duplicate your folder before first run of spoofed version in case Roblox updates.

IF ROBLOX UPDATES THEN YOU MUST REDO ALL OF THESE STEPS + CLEAR ANY OTHER VERSIONS IN YOUR VERSIONS FOLDER TO AVOID CONFLICT.
(Save the spoofed version in the folder as backup if you want, as "spoof").
